Garden sensor node — UNO Q wiring schematic (v4)

Soil sensors are powered at 3.3V, SIG wired directly to the analog pin — no divider resistors in this build. Only the SD card module runs on the 5V rail.

Qwiic chain (independent, daisy-chained) +3.3V rail (shared) GND rail (shared) SDA bus — I2C data (shared) SCL bus — I2C clock (shared) +5V rail (SD card module only) Direct analog signal → A0/A1 (no divider)
No voltage-divider network is used on the soil sensors — SIG is wired straight to the analog pin, powered at 3.3V (not 5V — only the SD card module is on the 5V rail). Calibration in sketch.ino (SOIL_DRY_ADC=1020, SOIL_WET_ADC=350) is against that raw, undivided signal — re-calibrate per unit if readings look off; note the firmware's own comment still describes this as a 5V-scale reading, which is now stale against the actual 3.3V wiring.
